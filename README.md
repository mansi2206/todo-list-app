# ✅ To-Do List App

A responsive **To-Do List App** built using **HTML, CSS, and JavaScript**. It provides a simple and intuitive interface to manage daily tasks efficiently.

## ✨ Features

- ➕ Add new tasks
- ❌ Delete tasks
- ✔️ Mark tasks as completed
- 🧹 Clear and user-friendly interface
- 📱 Responsive design
- ⚡ Fast and lightweight

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)

---

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/mansi2206/todo-list-app.git
```

### Navigate to the project folder

```bash
cd todo-list-app
```

### Run the project

Open `index.html` in your preferred web browser.
